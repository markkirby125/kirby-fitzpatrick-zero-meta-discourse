## Overview

The **kirby-fitzpatrick-zero-meta-discourse** skill transforms cognitive writing science into deterministic rules for AI coding assistants, code reviews, and system documentation.

## Quick Installation & Universal Setup

Add this skill directly to your coding assistant by pasting the **Magic Prompt** below into your agent chat:

```markdown
@agent Install the "kirby-fitzpatrick-zero-meta-discourse" skill:
1. Ensure ~/.gemini/config/skills, ~/.cursor/skills, ~/.cursor/skills-cursor, ~/.codeium/windsurf/skills, ~/.grok/skills, ~/.kimi-code/skills, and ~/.reasonix/skills exist.
2. Clone https://github.com/markkirby125/kirby-fitzpatrick-zero-meta-discourse.git to ~/.agents/skills/kirby-fitzpatrick-zero-meta-discourse.
3. Symlink ~/.agents/skills/kirby-fitzpatrick-zero-meta-discourse to all local AI app skill directories.
```

## Core Patterns

- **Zero Meta Discourse**: Zero Meta-Discourse Rule: ban announcements like 'In this section I will...', 'The above code shows...'. Deliver pure facts.
- **Practical Application**: Streamlining AI assistant responses to pure code diffs and verifiable facts.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
